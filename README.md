# tarot-spread-builder

Pick a tarot spread, place a card in each position, and preview the reading. No build step — open `index.html` directly, or serve the folder with any static file server.

- **Spreads**: One Card, Two Card, Three Card, Hexagram, Horseshoe, Celtic Cross
- **Randomize**: fills every position with a random, non-repeating card (with an "Allow reversed cards" option)
- Installable as a PWA (offline support via `sw.js`)
